# Chrome Web Store 截图物料

当前目录中的旧截图是宣传构图稿，不再作为上架素材使用：它们包含与实际界面不一致的深色布局、英文标签和虚构网络数据。

旧图已移入 `legacy/`，仅作历史参考。

当前已准备以下两张可上传截图：

- `store-screenshot-01-toolbox.png`：扩展工具列表，展示搜索、分类和真实工具卡片。
- `store-screenshot-02-workspace.png`：全页 Base64 工作区，展示脱敏输入和真实处理结果。

规格：1280×800、24 位 PNG、RGB、无透明层。当前 2 张，符合至少 1 张且不超过 5 张的限制。截图不得包含 Cookie、Token、手机号、内部域名、真实业务数据或未实现的按钮/功能。

建议测试数据：

```json
{"name":"demo","enabled":true,"items":[1,2,3]}
```

截屏完成前不要把目录中的旧图直接上传；上架文案和截图应与即将提交的扩展包保持一致。

## DevTools 截图测试页

在项目目录运行：

```bash
node store-assets/test-server.js
```

然后打开终端输出的本地地址，点击页面按钮（页面加载时也会自动发送一次请求），打开 DevTools，进入「开发匣」面板并刷新页面。这样生成的请求体和响应体只包含脱敏的 `demo` 数据。
